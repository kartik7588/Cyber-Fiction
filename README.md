# CYBERFICTION - 3D Animated Website

CYBERFICTION is a Web responsive 3D animated website built using HTML, CSS, and JavaScript. It incorporates modern web development techniques and animations to create an engaging user experience.

**To view the project, visit:** [kartik7588.github.io/Cyber-Fiction/](https://kartik7588.github.io/Cyber-Fiction/)
## Features

- **3D Animation**: Smooth animations using GSAP (GreenSock Animation Platform) and Locomotive Scroll for enhanced interactivity.
- **Custom Fonts**: Includes the Gilroy font for a modern and clean typography style.
- **Canvas Animation**: Dynamic canvas rendering for a visually appealing scrolling effect.
- **Multi-Page Sections**: Organized into multiple sections with unique content and animations.

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling and responsive design.
- **JavaScript**: For animations and interactivity.
- **GSAP**: For advanced animations.
- **Locomotive Scroll**: For smooth scrolling and scroll-based animations.


## How to Run

1. Clone the repository or download the project files.
2. Open the `index.html` file in any modern web browser.
3. Enjoy the interactive and animated experience!

## Dependencies

This project uses the following external libraries:

- [GSAP](https://greensock.com/gsap/) for animations.
- [Locomotive Scroll](https://locomotivemtl.github.io/locomotive-scroll/) for smooth scrolling.

These libraries are included via CDN links in the `index.html` file.
